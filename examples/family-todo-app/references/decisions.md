# Decisions

Every choice from the interview, with the reason.

| Topic | Decision | Why | Picked by |
|---|---|---|---|
| Idea | I want a simple shared to-do app for my family. We keep forgetting chores and groceries, so everyone should see the list and tick things off from their phones. | Everything else depends on this. Messy is fine! | Owner |
| Name | Family Todo App | Your skill and project folder get this name. | Owner |
| Your experience | Beginner | never really coded; explain everything simply | Owner |
| Users | A small group | family, team or class; needs simple logins | Owner |
| Scale | Under 100 | free tiers are plenty | Owner |
| Reliability | Annoying | people rely on it, but nobody loses money | Owner |
| Must-haves | Shared lists, add and tick off tasks, assign a task to a person, due dates, reminders by email | Your first version (the MVP, 'minimum viable product') — small and working beats big and broken. | Owner |
| Later | A shopping mode that sorts groceries by aisle; a weekly chore rotation | We'll write these down so the AI doesn't build them too early. | Owner |
| Platform | Website | works in any browser, on phone and computer; fastest to build | Owner |
| Look & feel | Bright and friendly, big buttons, something like Todoist but simpler | Gives the AI a design direction so it doesn't look generic. | Owner |
| Frontend | Next.js | Next.js does screens and server code in one place, and AI agents build it reliably. | SkillTalk default |
| Backend | Use a ready-made backend | It gives you a database and logins without writing server code. | SkillTalk default |
| Data | Supabase (Postgres) | online database with logins built in; free to start | Owner |
| Logins | Google login | one click with their Google account | Owner |
| AI features | Maybe later | we'll leave room for it | Owner |
| Hosting | Vercel | one-click hosting for websites; free for small projects | Owner |
| AI builder | Claude Code | gets the full setup: hooks, helper agents, commands | Owner |
| Budget | $0 | free tiers only | Owner |
| Timeline | About 2 weeks | Helps size the first milestone. | Owner |
| Privacy | No | normal everyday data | Owner |
| Anything else | My mum isn't techy, so it has to be super obvious. | Last chance to add your personal touch. | Owner |
| Scale tier | Starter | small user base — managed hosting and free tiers cover everything; keep it simple. | SkillTalk (from users + reliability) |
