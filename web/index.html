How to install it
  1. Claude Code: unzip into your-project/.claude/skills/ (or ~/.claude/skills/ for all projects). Or run skilltalk install <folder> --target project.
  2. Other agents (Codex, Cursor, Gemini CLI…): run skilltalk install <folder> --target agents --project-dir your-project (or python3 <folder>/setup/bootstrap.py your-project).
  3. Then tell your agent: "Use the skill and start Milestone 0." It sets up the safety net (hooks, checks, GitHub, automatic deploys) by itself, then builds your app step by step.
